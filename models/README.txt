Put your character here as models/character.vrm (VRM 0.x or 1.0). If several .vrm files are present,
"character.vrm" wins, otherwise the first one alphabetically. Restart Moss to load it.

The character is NOT included in this repository.

Moss's body in the demo is "Zainab-Chan" by mimenn_ (VRoid Hub, VRM 1.0):
https://hub.vroid.com/en/characters/542563936448829639/models/1717281170322434139
Its license requires credit and does not allow redistribution or modification, so download it yourself from that page
and save it here as character.vrm. Always read a model's own license on its page before using it.

Free places to find or make a character: VRoid Studio (make your own, exports VRM), VRoid Hub, Booth.
Use a model whose license allows what you plan to do with it.
